# `sa_evaluate_expressions`

- **Mode**: Read-Only

## Contract & Constraints

Operators and algebraic/rounding functions use exact System.Decimal (28-29 significant digits); transcendental and extended mathematical functions evaluate internally in IEEE-754 binary64 (~15 significant digits) narrowed via ToDecimalOrNull (overflow at |x| >= 7.9e27). Expressions are evaluated in array order and may reference scalar/array variables and earlier results (calculatorVersion: 4).

## Arguments (`inputSchema`)

| Argument | Type | Req | Constraints / Default | Description |
|---|---|---|---|---|
| `variables` | `object` | No | - | Optional map of scalar variable names to decimal numbers (combined scalar + array variables at most 50 entries; names match [A-Za-z_][A-Za-z0-9_]{0,63} and cannot equal a function name). |
| `arrayVariables` | `object` | No | - | Optional map of 1D array variable names to finite decimal arrays (empty [] allowed; at most 512 items per array, 2048 total input elements across arrayVariables, and 4096 total elements across batch; combined scalar + array variables at most 50 entries). |
| `expressions` | `array` | Yes | - | Ordered list of expressions to evaluate (1..20 items). Later expressions may reference earlier ones. |
| `decimalPlaces` | `integer` | No | min: `0`, max: `10` | Optional rounding applied to expression results on output (0..10, MidpointRounding.AwayFromZero). Variables are not rounded. |

## Example Call

```json
{
  "variables": {
    "close": 2950,
    "atr": 48.5
  },
  "expressions": [
    {
      "name": "stop",
      "expression": "close - 2 * atr"
    }
  ]
}
```

## Common Errors

- `INVALID_ARGUMENT`: Missing required argument, wrong type/shape, invalid date range, or mutually exclusive arguments.
- `LIMIT_EXCEEDED`: Requested count, window, symbol list, or estimated response tokens exceeded server bounds.
